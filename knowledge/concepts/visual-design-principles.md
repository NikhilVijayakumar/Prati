# Visual Design Principles

The design guidance describes a calm visual language built on simplicity, consistent alignment, typography-led hierarchy, limited accent color, generous whitespace and subtle depth. Motion should communicate state or guide attention. Reusable patterns should behave consistently and visual detail should support readability.

This is documented design intent, not evidence that every Prati component meets it. Astra and BAVANS are named in the source material; brand-specific direction should not automatically become a universal component-library contract.

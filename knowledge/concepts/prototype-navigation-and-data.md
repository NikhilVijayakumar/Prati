# Prototype Navigation and Data

The prototype runtime describes screen and workflow navigation, mock datasets and local persistence to support interactive demonstrations. It is intended to simulate application flows without requiring a production backend. Local persistence is not a production database, synchronization system, access-control mechanism or multi-user store.

Consult the current runtime interfaces and tests before relying on a particular routing, storage, recovery or generation behavior.

# Architecture and Security Review Practice

Review public interfaces, dependency boundaries, presentation state, theme and localization practices, browser-only APIs and reproducible builds against the actual repository. Security review topics include untrusted content and injection, sensitive data, dependencies and build inputs. Identify the affected file, observation, impact and corrective action; distinguish historical findings from a newly executed audit.

Audit prompts and scoring templates are working procedures rather than proof of conformance. Select applicable checks and report commands, limitations and results.

# Design

The scoped package keeps existing exports and peers; its CommonJS entry uses a `.cjs` extension under `type: module`. GitHub CI checks pushes to main. A tag workflow validates the tag, tests and builds before publishing using npm OIDC, with minimal permissions. Account ownership, trusted publisher configuration and branch protections are external prerequisites. Failure of any check blocks publication. No component or browser interface changes. `knowledge/architecture/library-compatibility.md` and PKG-001?003 apply. No ADR: this applies the existing packaging guide without changing component architecture.

Export the existing bundled template map through the library barrel. Resolve scrollbar colors in the supported whole-styles callback rather than nested callbacks. Keep Node filesystem imports lazy and runtime-only to avoid browser build externalization while preserving the Node file fallback. Existing public interfaces and peer ranges remain; no ADR is needed for these localized corrections. Browser consumers still receive a failure result for templates unavailable without a Node base path.

The tag job installs npm 11.15.0, validates the release and uses OIDC to stage rather than directly publish. npm requires maintainer 2FA approval to promote the staged version; a successful job alone is not publication. The package and browser interfaces are unchanged; no ADR is needed for this release process adjustment (PKG-002; `knowledge/architecture/library-compatibility.md`).

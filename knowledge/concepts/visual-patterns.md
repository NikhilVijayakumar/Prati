# Visual Interface Patterns

Cards group related information with a clear heading, content and optional action; heroes prioritize one message and action. Tables favor legible columns and restrained separators; toolbars group related actions. Forms need clear labels and grouping; side panels preserve context; notifications give concise feedback.

These are design patterns rather than a guarantee that each existing component implements all suggested behavior. For example, the documented DataTable does not itself sort, filter or paginate despite the general table-pattern guidance mentioning those interactions.

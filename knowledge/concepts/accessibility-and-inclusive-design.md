# Accessibility and Inclusive Design

Use meaningful elements, accessible names, logical headings, appropriate roles and clear form labels. Interactive controls need keyboard operation and visible focus; state must not depend on color alone. Evaluate text and controls for contrast, target size, zoom, reflow and translated text. Respect reduced-motion preferences where motion is used.

The mockup guide proposes 4.5:1 text contrast and 44px targets as design targets, but also prescribes generator-specific metadata and exact styling. Treat those implementation details as mockup guidance, not verified facts about the library. Automated checks alone do not establish accessibility conformance.
